# Carrel

A private desk for a packet. Ask the pages in front of you. Nothing leaves without a call slip.

Carrel is not a chatbot with a sidebar. The packet is the room.

- **Ask the packet** — you see the passages that will be read. Answers quote the page or stay quiet.
- **Fill a call slip** — names, phones, and record numbers are struck. You stamp the cleaned question. The packet stays on the desk.
- **Keep** — pin a fact on purpose. Nothing is remembered in silence.
- **Find** — search the page with no network.

Receipts record every time something left the browser.

Not a clinician. Not HIPAA. Not safe for care. Ask still sends the passages you approve to a remote language model — on purpose, in the open.

## Run

```bash
npm install
npm run dev
```

Sit with the synthetic demo packet (a fictional person) before pasting anything of your own.

## Stack

TanStack Start, React 19, Tailwind v4, Zustand, xAI for Ask and call-slip lookup.
